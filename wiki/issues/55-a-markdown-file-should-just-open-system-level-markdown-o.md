# Decision

Worth reading, mainly for the link back to my own projects. Joshua Morris argues that Markdown should open directly in the operating system the way PDF does, and gives concrete positions: CommonMark + GFM as the baseline, preserve unknown syntax, previews that run no scripts and work offline, and the original file as the only source of truth. This relates directly to the positioning of md2wechat-skill, wechat-markdown-editor, and obsidian-md2wechat, and can also be material for the Official Account direction of "knowledge management and good layout."
